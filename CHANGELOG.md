# Changelog

## 1.0.3

- Prepared the repository for the current Omarchy Plugins marketplace submission rules.
- Updated installation, update, and removal documentation to use Omarchy's native plugin manager.
- Added explicit `MIT` license metadata to `manifest.json`.
- Documented that KLM only edits its own marked block in `~/.config/hypr/input.lua` after an explicit configuration change.
- Documented safe cleanup before plugin removal and restoration of the stock keyboard-layout widget when desired.
- Added repository-level validation guidance for maintainers.

## 1.0.2

- Replaced XKB `grp:alt_shift_toggle` with symmetric native Hyprland release bindings for Alt+Shift.
- Added automatic migration and shortcut repair support.
- Added Imagine it website link in the settings footer.
